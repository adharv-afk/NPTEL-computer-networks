# Computer Networks Quiz

A simple, interactive quiz website for practising NPTEL Computer Networks assignments from Weeks 1–12.

## Features

- Practice questions week by week or across all weeks.
- Choose the number of questions for each quiz.
- Shuffle questions or practise in the original order.
- Get instant feedback when selecting an answer.
- View your score as you progress through the quiz.
- Review questions you answered incorrectly.
- Save missed questions in your browser for later revision.
- Responsive design for desktop and mobile devices.
- Green and white interface for a clean, comfortable experience.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Open the website.
2. Select a week or choose all weeks.
3. Choose the number of questions.
4. Select the question order.
5. Click **Start quiz**.
6. Select an answer to receive instant feedback.
7. Review your score and practise missed questions.

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Start practising.

No backend or database is required.

## Deployment

This website can be hosted for free using GitHub Pages.

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under the build and deployment settings, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Click **Save**.
6. Open the published website using the URL shown in the Pages settings.
